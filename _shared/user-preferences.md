# 研究方向偏好

## 核心方向（高优先级）

| 方向 | 关键词 | 说明 |
|------|--------|------|
| Agent Architecture | agent framework, multi-agent, agentic, langchain, langgraph, tool use, agent orchestration, function calling, react agent, agent training | 多智能体系统、agent 框架设计、工具使用 |
| LLM Inference | vllm, sglang, kv cache, speculative decoding, model quantization, pagedattention, continuous batching, inference serving, llm serving | 推理优化、服务框架 |
| GPU Architecture & Cluster | gpu cluster, gpu architecture, distributed inference, model parallelism, distributed training | 集群管理和 GPU 架构 |
| Diffusion Model | diffusion model, flow matching, video generation, image generation | 生成模型方向 |

## 兴趣方向（低优先级）

| 方向 | 关键词 | 说明 |
|------|--------|------|
| World Model | world model, latent dynamics, model-based rl, video prediction | 兴趣，非核心 |
| Robotics | embodied ai, robot manipulation, sim-to-real, vla, policy learning | 兴趣，非核心 |

## 过滤规则

1. 核心方向的论文优先推荐
2. 兴趣方向只推有突破性/高质量的工作，不硬凑
3. 以下方向直接跳过：医学影像、天气预报、语音/音频、OCR、金融交易、蛋白质/药物
